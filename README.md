# Mathematics-review

数学の問題を登録し、習得状況に応じて復習すべき問題を提案する Web アプリです。
ビルド不要の静的ファイルだけで動きます。

## 使い方

- `index.html` をブラウザで開く（ダブルクリックで開いても動きます）
- GitHub Pages で公開する場合: リポジトリの Settings → Pages で、このブランチのルートを公開元に指定する

### 画面

| タブ | 内容 |
| --- | --- |
| 復習 | 今日復習すべき問題を 1 問ずつ表示。要点を確認して自己判定する |
| 問題一覧 | 検索・状況での絞り込み・並べ替え、編集（問題文・出典・要点・習得状況。`$…$` / `$$…$$` で数式）、削除、「今すぐ復習」 |
| AIで追加 | チャット AI（ChatGPT・Claude など）に問題文・出典を書き起こさせ、出典を確認・修正し、要点は自分で書いて「追加」または「編集して追加」 |
| データ | JSON への書き出し・読み込み、復習ルールの一覧 |

## 習得状況と復習ルール

習得状況は **未判定 / × / ○ / ◎** の 4 段階です。

| 状況 | 次の復習 | 判定結果による変化 |
| --- | --- | --- |
| 未判定 | すぐ | 解けた → ○ ／ 解けなかった → × |
| × | 1 日後 | 解けた → ○ ／ 解けなかった → × |
| ○ | 3 日後 → 7 日後 → 14 日後（要点即答の回数で伸びる） | 要点をすぐ答えられた → 回数 +1、**累計 3 回で ◎** ／ 解けたが要点はすぐ出なかった → ○ のまま ／ 解けなかった → ×（回数リセット） |
| ◎ | 30 日後 | 要点をすぐ答えられた → ◎ のまま ／ 要点がすぐ出なかった → ○（回数リセット） ／ 解けなかった → × |

- 「要点をすぐ答えられた」かどうかは自己申告です。
- 即答の回数は ○ になってから数えます（未判定・× から解けた回は数えません）。
- 復習日は日付単位で判定します（夜に復習しても、次の予定日の朝から表示されます）。
- 今日の復習は × → 未判定 → ○ → ◎ の順、同じ状況の中では予定日が古い順に出ます。
- 編集画面で習得状況を直接変えると、その日に判定したものとして次回の復習日を計算し直します。

## AI で追加（無料）

手持ちのチャット AI（ChatGPT・Claude・Gemini などの無料プランで可）を使います。アプリ自体は AI と通信せず、API キーや料金はかかりません。

1. 「指示文をコピー」を押し、チャット AI に貼り付ける。問題の写真を添付するか、問題の文章を続けて書いて送る
2. AI の返答（コードブロック）をコピーし、「AI の返答を貼り付けて読み込む」に貼り付けて「読み込む」
3. 読み取った候補の問題文を確認し、出典を必要に応じて直し、要点を自分で書いて「追加」または「編集して追加」（追加した問題は「未判定」から始まる）

AI には `【問題】` `【出典】` の見出しで区切ったテキストを返させます（`js/proposal-parser.js` で読み取り）。
JSON にしないのは、JSON の中では `\frac` や `\times` などの LaTeX が別の文字に化けやすいためです。
要点は AI に書かせず、読み込んだ候補ごとの入力欄に自分で書きます（空のまま追加して、あとで一覧の「編集」から書くこともできます）。
AI が書き起こした問題文には誤りが含まれることがあるので、追加する前に確認してください。

## データの保存

データはブラウザの localStorage に保存されます。ブラウザのデータを消すと失われ、別の端末・別のブラウザとは共有されません。
「データ」タブから JSON に書き出してバックアップしてください。

## 開発

```sh
npm test   # 復習ロジックと返答の読み取りのテスト。依存パッケージなし
```

- `js/logic.js` … 習得状況・復習日の計算（UI に依存しない）
- `js/app.js` … 画面
- `js/ai-import.js` … 「AIで追加」画面
- `js/proposal-parser.js` … チャット AI の返答から登録候補を取り出す
- `vendor/katex/` … 数式表示用の [KaTeX](https://katex.org/) 0.16.11（MIT License）。オフラインでも数式を表示できるよう同梱
