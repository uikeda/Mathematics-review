# Mathematics-review

数学の問題を登録し、習得状況に応じて復習すべき問題を提案する Web アプリです。
ビルド不要の静的ファイルだけで動きます。

## 使い方

- `index.html` をブラウザで開く（ダブルクリックで開いても動きます）
- GitHub Pages で公開する場合: リポジトリの Settings → Pages で、このブランチのルートを公開元に指定する

### 画面

| タブ | 内容 |
| --- | --- |
| 復習 | 今日復習すべき問題を 1 問ずつ表示。要点を確認して自己判定する |
| 問題一覧 | 検索・状況での絞り込み・並べ替え、編集、削除、「今すぐ復習」 |
| 問題を追加 | 問題文（必須）・出典・要点・習得状況を入力。`$…$` / `$$…$$` で数式（KaTeX） |
| AIで追加 | 問題の写真や文章を送ると、AI（Claude）が問題文・出典・要点を書き起こして登録候補を出す。確認して「追加」 |
| データ | JSON への書き出し・読み込み、復習ルールの一覧 |

## 習得状況と復習ルール

習得状況は **未判定 / × / ○ / ◎** の 4 段階です。

| 状況 | 次の復習 | 判定結果による変化 |
| --- | --- | --- |
| 未判定 | すぐ | 解けた → ○ ／ 解けなかった → × |
| × | 1 日後 | 解けた → ○ ／ 解けなかった → × |
| ○ | 3 日後 → 7 日後 → 14 日後（要点即答の回数で伸びる） | 要点をすぐ答えられた → 回数 +1、**累計 3 回で ◎** ／ 解けたが要点はすぐ出なかった → ○ のまま ／ 解けなかった → ×（回数リセット） |
| ◎ | 30 日後 | 要点をすぐ答えられた → ◎ のまま ／ 要点がすぐ出なかった → ○（回数リセット） ／ 解けなかった → × |

- 「要点をすぐ答えられた」かどうかは自己申告です。
- 即答の回数は ○ になってから数えます（未判定・× から解けた回は数えません）。
- 復習日は日付単位で判定します（夜に復習しても、次の予定日の朝から表示されます）。
- 今日の復習は × → 未判定 → ○ → ◎ の順、同じ状況の中では予定日が古い順に出ます。
- 編集画面で習得状況を直接変えると、その日に判定したものとして次回の復習日を計算し直します。

## AI で追加（Claude API）

- 使うには [Anthropic の API キー](https://console.anthropic.com/) が必要です（claude.ai の有料プランとは別の、従量課金の API 契約）。「AIで追加」タブの「AI の設定」に入力します。
- キーはそのブラウザの localStorage にだけ保存され、ブラウザから直接 `api.anthropic.com` に送られます。サーバーは経由しません。共用の端末では使い終わったら「キーを削除」してください。
- モデルは Claude Opus 5.5（既定）/ Sonnet 5.5 / Haiku 5.5 から選べます。
- 応答は JSON 形式（構造化出力）で受け取り、候補ごとに「追加」「編集して追加」を選べます。AI が追加した問題は「未判定」から始まります。
- 安全上の理由で応答が断られた場合は、サーバー側で別のモデルに切り替えて再実行する設定（`fallbacks: "default"`）を Opus / Sonnet で有効にしています。
- 会話の履歴（画像を含む）は送信のたびに毎回送られるので、会話が長いほど 1 回あたりの料金が増えます。

## データの保存

データはブラウザの localStorage に保存されます。ブラウザのデータを消すと失われ、別の端末・別のブラウザとは共有されません。
「データ」タブから JSON に書き出してバックアップしてください。

## 開発

```sh
npm test   # 復習ロジック（js/logic.js）のテスト。依存パッケージなし
```

- `js/logic.js` … 習得状況・復習日の計算（UI に依存しない）
- `js/app.js` … 画面
- `js/ai-chat.js` … AI チャット画面（Claude API の呼び出し）
- `vendor/anthropic-sdk/` … [Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript) 0.133.0（MIT License）を esbuild でブラウザ用の 1 ファイルにまとめたもの
- `vendor/katex/` … 数式表示用の [KaTeX](https://katex.org/) 0.16.11（MIT License）。オフラインでも数式を表示できるよう同梱
