# Mathematics-review

数学の問題を登録し、習得状況に応じて復習すべき問題を提案する Web アプリです。
ビルド不要の静的ファイルだけで動きます。

## 使い方

- `index.html` をブラウザで開く（ダブルクリックで開いても動きます）
- GitHub Pages で公開する場合: リポジトリの Settings → Pages で、このブランチのルートを公開元に指定する

### 画面

| タブ | 内容 |
| --- | --- |
| 復習 | 今日復習すべき問題を 1 問ずつ表示し、自己判定する |
| 問題一覧 | 検索・状況での絞り込み・並べ替え、編集（問題文・写真・出典・習得状況。`$…$` / `$$…$$` で数式）、削除、「今すぐ復習」 |
| 問題を追加 | 「AI で書き起こす」（チャット AI に問題文・出典を書き起こさせる）か「写真をそのまま」（写真を問題文にする）で候補を作り、出典を確認・修正して「追加」または「編集して追加」 |
| データ | JSON への書き出し・読み込み、復習ルールの一覧 |

## 習得状況と復習ルール

習得状況は **未判定 / × / ○ / ◎** の 4 段階です。

| 状況 | 次の復習 | 判定結果による変化 |
| --- | --- | --- |
| 未判定 | すぐ | 解けた → ○ ／ 解けなかった → × |
| × | 1 日後 | 解けた → ○ ／ 解けなかった → × |
| ○ | 3 日後 → 7 日後 → 14 日後（要点即答の回数で伸びる） | 要点をすぐ答えられた → 回数 +1、**累計 3 回で ◎** ／ 解けたが要点はすぐ出なかった → ○ のまま ／ 解けなかった → ×（回数リセット） |
| ◎ | 30 日後 | 要点をすぐ答えられた → ◎ のまま ／ 要点がすぐ出なかった → ○（回数リセット） ／ 解けなかった → × |

- 記録するのは問題文（写真を含む）・出典・習得状況だけです。「要点をすぐ答えられた」かどうかは、頭の中で答えて自己申告します。
- 即答の回数は ○ になってから数えます（未判定・× から解けた回は数えません）。
- 復習日は日付単位で判定します（夜に復習しても、次の予定日の朝から表示されます）。
- 今日の復習は × → 未判定 → ○ → ◎ の順、同じ状況の中では予定日が古い順に出ます。
- 編集画面で習得状況を直接変えると、その日に判定したものとして次回の復習日を計算し直します。

## 問題を追加

### AI で書き起こす（無料）

手持ちのチャット AI（ChatGPT・Claude・Gemini などの無料プランで可）を使います。アプリ自体は AI と通信せず、API キーや料金はかかりません。

1. 「指示文をコピー」を押し、チャット AI に貼り付ける。問題の写真を添付するか、問題の文章を続けて書いて送る（写真は複数枚、1枚に複数問でも可）
2. AI の返答（コードブロック）をコピーし、「AI の返答を貼り付けて読み込む」に貼り付けて「読み込む」。何回かに分けて貼り付けると候補が後ろに追加されていく（同じ問題文の候補は除外）
3. 読み取った候補の問題文を確認し、出典を必要に応じて直して「追加」または「編集して追加」（追加した問題は「未判定」から始まる）

AI には `【問題】` `【出典】` の見出しで区切ったテキストを返させます（`js/proposal-parser.js` で読み取り）。
JSON にしないのは、JSON の中では `\frac` や `\times` などの LaTeX が別の文字に化けやすいためです。
AI が書き起こした問題文には誤りが含まれることがあるので、追加する前に確認してください。

### 写真をそのまま

1. 「写真をそのまま」を選び、「写真を選ぶ」で問題の写真を選ぶ（複数可）。写真 1 枚ごとに 1 問の候補になる。「まとめて1問にする」にチェックすると、選んだ写真をまとめて 1 問にする
2. 出典を書いて「追加」または「編集して追加」（問題文を書き足すこともできる）

写真は長辺 1600 ピクセルの JPEG に縮小し、ブラウザの IndexedDB に保存します（localStorage は容量が 5MB 前後と小さいため）。
登録済みの問題にも、一覧の「編集」から写真を付けたり外したりできます。

## データの保存

問題はブラウザの localStorage、写真は IndexedDB に保存されます。ブラウザのデータを消すと失われ、別の端末・別のブラウザとは共有されません。
「データ」タブから JSON に書き出してバックアップしてください（写真も JSON の中に含めて書き出します）。

## 開発

```sh
npm test   # 復習ロジックと返答の読み取りのテスト。依存パッケージなし
```

- `js/logic.js` … 習得状況・復習日の計算（UI に依存しない）
- `js/app.js` … 画面
- `js/ai-import.js` … 「問題を追加」画面
- `js/image-store.js` … 写真の縮小と IndexedDB への保存
- `js/proposal-parser.js` … チャット AI の返答から登録候補を取り出す
- `vendor/katex/` … 数式表示用の [KaTeX](https://katex.org/) 0.16.11（MIT License）。オフラインでも数式を表示できるよう同梱
